Como funciona o aprendizado

1. Cada rodada guarda o número e as três porcentagens.

2. Cada par de rodadas gera uma transição: quanto cada coluna subiu ou desceu.

3. Após 20 registros, o sistema compara as duas transições mais recentes com sequências anteriores.

4. Se encontrar exemplos semelhantes, calcula uma sugestão pela média das mudanças seguintes.

A sugestão é uma análise dos seus registros, não uma previsão da roleta.
